# public/downloads — فایل‌های نصبیِ نرم‌افزار (خارج از گیت)

فایل‌های حجیمِ نصبی (`.msi` / `.rar` / `.exe` / `.zip`) اینجا **آپلودِ دستی روی سرور** می‌شوند و
**داخلِ گیت کامیت نمی‌شوند** — چون از سقفِ ۱۰۰ مگابایتیِ گیت‌هاب رد می‌شوند. قاعده‌ی
`.gitignore` (در `frontend/.gitignore`) این فایل‌ها را نادیده می‌گیرد؛ فقط همین پوشه با
`.gitkeep` در ریپو می‌ماند.

## چطور کار می‌کند (بی‌دردسر با pull/build)
`next build` کلِ محتوای `public/` را عیناً به `out/` کپی می‌کند. پس هر فایلی که اینجا باشد
سرِ بیلد به `out/downloads/…` می‌رود و روی `https://fmg-tech.ir/downloads/…` سرو می‌شود.

چون فایل **untracked/ignored** است:
- `git pull` هیچ‌وقت حذفش نمی‌کند،
- `git reset --hard` هم فقط فایل‌های tracked را دست می‌زند،
- بیلد هر بار دوباره از اینجا برمی‌داردش.
(تنها چیزی که پاکش می‌کند `git clean -fdx` است — در روتینِ pull اجرا نکنید.)

## افزودن/آپدیتِ یک نرم‌افزار
1. فایل را با Plesk File Manager (یا FTP) در همین پوشه‌ی `frontend/public/downloads/` آپلود کنید،
   با نامِ انگلیسیِ kebab-case (مثلاً `satir-report-2.7.5.msi`).
2. لینکِ دانلود در `frontend/src/app/(public)/training/page.tsx` (آرایه‌ی `SOFTWARE`) به همان
   نام اشاره می‌کند.
3. برای نسخه‌ی جدید فقط فایل را جایگزین و لینک/نسخه را در همان آرایه به‌روز کنید.
